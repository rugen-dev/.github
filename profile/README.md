  with rollback netcode for online play.

Your existing MUGEN characters, stages and screenpacks run unchanged on
Windows, Linux, macOS and Steam Deck. rugen builds on the content and
formats of [M.U.G.E.N](https://www.elecbyte.com/) by Elecbyte and stays
compatible with [Ikemen GO](https://github.com/ikemen-engine/Ikemen-GO);
[see how they compare](https://rugen.dev/docs/engine/compared/).

## Repositories

| Repository | What it is |
| --- | --- |
| [**rugen-engine**](https://github.com/rugen-dev/rugen-engine) | The game: loads MUGEN 1.1 / Ikemen GO content, Arcade, VS, Arena, Training and online play with rollback. |
| [**rugen-server**](https://github.com/rugen-dev/rugen-server) | Self-hostable online hub: accounts, rooms, ranked Elo, spectators and a UDP / WebSocket relay. One binary, SQLite inside. |
| [**rugen-char-template**](https://github.com/rugen-dev/rugen-char-template) | Start a character repo: layout, `rugen.json`, verify and release workflows. |
| [**rugen-stage-template**](https://github.com/rugen-dev/rugen-stage-template) | Start a stage repo: layout, `rugen.json`, convert and release workflows. |
