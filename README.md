## rugen in short

rugen is a free, open-source, M.U.G.E.N-compatible 2D fighting game engine
written in Rust. Your existing MUGEN and Ikemen GO characters, stages and
screenpacks run unchanged on Windows, Linux, macOS and Steam Deck, with
rollback netcode for online play.

## Get involved

- **Found a bug or want a feature?** Open an issue on
  [rugen-engine](https://github.com/rugen-dev/rugen-engine/issues).
- **Want to contribute code?** Start with
  [architecture](https://rugen.dev/docs/engine/architecture/),
  [building](https://rugen.dev/docs/engine/building/) and
  [contributing](https://rugen.dev/docs/engine/contributing/).
- **Making content?** Start a fighter from
  [rugen-char-template](https://github.com/rugen-dev/rugen-char-template) or a stage from
  [rugen-stage-template](https://github.com/rugen-dev/rugen-stage-template).
